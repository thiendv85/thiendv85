## CRITICAL Findings

### Security

**SEC-C1** — Client-side PIN auth (`utils/supabase.ts:13-16`, `pages/Settings.tsx:1220`)
`VITE_ADMIN_PIN=2026` is inlined in client bundle. Default `'2026'` is current year. Trivially extractable and guessable.

**SEC-C2** — Hardcoded Supabase URL+key in source (`utils/supabase.ts:5-6`)
Permanent credential in git history. Move to `import.meta.env` only.

**SEC-C3** — Gemini API key in client bundle (`vite.config.ts:26-27`)
`define` bakes raw string into JS. Anyone can extract and abuse quota/cost. Move to Edge Function proxy.

**SEC-C4** — RLS policies grant all auth users full access (`supabase/rls_policies.sql`)
Every policy uses `USING (true)`. No `auth.uid()` checks. Cross-user data leakage.

### Code Quality

**TS-C1** — TypeScript build fails (46 errors) — `App.tsx:633`, `pages/BackorderAnalytics.tsx:985`, `utils/inventoryEngine.ts:782`, `utils/searchLogic.ts:160`, `back-order-dashboard/` 20+ alias errors.

**TS-C2** — Hardcoded Supabase key (`utils/supabase.ts:6`) — duplicates SEC-C2.

**TS-C3** — `window.navigateToLog` global mutation (`App.tsx:332`) — `any`-cast escape hatch, no cleanup.

### Performance

**PERF-C1** — `pg` in `dependencies` (`package.json:16`) — Node TCP driver, can't run in browser.

**PERF-C2** — Tailwind CDN runtime (`index.html:8`) — `<script src="https://cdn.tailwindcss.com">` ~350 KB JIT engine, blocks render, disables tree-shaking.

**PERF-C3** — Font Awesome CDN (`index.html:14`) — full icon library ~500 KB CSS + 300 KB fonts. `lucide-react` already bundled.

### Database

**DB-C1** — `check-escalation` N+1 (`supabase/functions/check-escalation/index.ts:38-65`) — separate workflow query per request.

**DB-C2** — `send-approval-email` N+1 auth lookup (`supabase/functions/send-approval-email/index.ts:44-47`) — `auth.admin.getUserById` per recipient.

**DB-C3** — `updateRequestStatus` non-atomic optimistic lock (`utils/supabase.ts:477-489`) — version read+write without `.eq('version', expected)` predicate. Concurrent updates silently win.
