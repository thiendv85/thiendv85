# Goal
Giúp người dùng khám phá, tìm kiếm và cài đặt các AI Skills chất lượng cao từ cộng đồng vào workspace hiện tại.

# Instructions

## 1. Tìm kiếm và Khám phá
Khi người dùng yêu cầu tìm skill, bạn hãy:
1. Đọc file `C:\Users\admin\awesome-agent-skills\README.md`.
2. Sử dụng `grep_search` hoặc `read_url_content` để tìm các từ khóa liên quan đến yêu cầu của người dùng trong danh sách repo.
3. Trình bày kết quả dưới dạng bảng:
   | Skill Name | Description | Source URL |
   |------------|-------------|------------|

## 2. Cài đặt Skill (Installation)
Nếu người dùng chọn một skill để cài đặt:
1. Kiểm tra xem đó là repo GitHub hay chỉ là một đoạn code/SKILL.md.
2. Nếu là repo GitHub:
   - Sử dụng `run_command` để `git clone` repo đó vào thư mục tạm `/tmp/`.
   - Tìm file `SKILL.md` (hoặc tương đương) trong repo đó.
   - Copy toàn bộ thư mục skill vào `.agent/skills/[skill-name]/`.
3. Nếu chỉ là `SKILL.md` trên web:
   - Sử dụng `read_url_content` để lấy nội dung.
   - Tạo thư mục `.agent/skills/[skill-name]/` và ghi file `SKILL.md`.
4. Thông báo cho người dùng sau khi cài đặt thành công và hướng dẫn cách kích hoạt (thường là tự động nhận diện).

## 3. Khuyến nghị Skill
Dựa trên ngữ cảnh dự án (ví dụ: đang làm về Supply Chain, UI/UX, hoặc Database), hãy chủ động gợi ý các skill phù hợp từ list `awesome-agent-skills`.

# Examples

## Ví dụ 1: Tìm skill xử lý CSV
**User:** "Tôi muốn thêm skill nào đó để phân tích file CSV dữ liệu tồn kho."
**Agent:** 
1. `grep_search` từ khóa "CSV" trong `README.md`.
2. Tìm thấy "CSV Summarizer" (`coffeefuelbump/csv-data-summarizer-claude-skill`).
3. Đề xuất: "Tôi tìm thấy skill **CSV Summarizer**. Bạn có muốn tôi cài đặt nó vào workspace không?"

## Ví dụ 2: Cài đặt skill
**User:** "Cài đặt skill CSV Summarizer đi."
**Agent:**
1. `git clone https://github.com/coffeefuelbump/csv-data-summarizer-claude-skill /tmp/csv-skill`.
2. `cp -r /tmp/csv-skill/ d:/App/v14/.agent/skills/csv-summarizer/`.
3. Thông báo: "Đã cài đặt xong skill **CSV Summarizer**. Bây giờ bạn có thể yêu cầu tôi phân tích file CSV bất kỳ."

# Constraints
- 🚫 KHÔNG cài đặt skill từ các nguồn không đáng tin cậy (ngoài list awesome-agent-skills unless user explicitly insists).
- ✅ Luôn kiểm tra cấu trúc `SKILL.md` sau khi cài đặt để đảm bảo Antigravity có thể đọc được.
- 📦 Giữ cấu trúc thư mục sạch sẽ trong `.agent/skills/`.
