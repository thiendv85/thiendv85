# Goal
Biến các file `.md` đơn lẻ thành một bộ não thứ hai (Second Brain) được tổ chức chuẩn xác. Giúp user tìm và tái sử dụng kiến thức/code cũ trong vòng 5 giây mà không cần nhớ đường dẫn hay tên file chính xác.

# Instructions

Khả năng của Skill này chia làm 2 nhánh chính: **LƯU TRỮ (Save)** và **TRUY XUẤT (Retrieve)**.

## 1. Khi được yêu cầu LƯU TRỮ (Save/Categorize Note)
- Phân tích nội dung ghi chú/tài liệu user muốn lưu.
- **Tạo Frontmatter YAML** bắt buộc ở đầu file markdown với cấu trúc:
  ```yaml
  ---
  title: [Tiêu đề ngắn gọn]
  date: [YYYY-MM-DD]
  category: [Phân loại chính - ví dụ: Frontend, Database, Workflow, Rules]
  tags: [3-5 tags viết thường, cách nhau bằng phẩy]
  ---
  ```
- **Tạo & Lưu File**: Lưu file vào thư mục `.agent/notes/` hoặc `docs/`. Tạo cây thư mục tương ứng với `category` để đảm bảo ngăn nắp (Ví dụ: `.agent/notes/frontend/react-query-setup.md`).
- **Phản hồi ngắn gọn**: Output bảng tóm tắt báo cáo file đã được lưu kèm các Thẻ (Tags) để user an tâm.

## 2. Khi được yêu cầu TRUY XUẤT (Retrieve/Reuse Note)
- **Truy tìm (Find)**: Dựa vào từ khóa của user (ví dụ: "tìm chuẩn code UI", "lấy file setup tailwind"), lập tức sử dụng công cụ `grep_search` để tìm `tags:` hoặc từ khóa tương đương trong thư mục `.agent/notes/` hoặc `docs/`.
- **Đọc hiểu (Comprehend)**: Đọc file tìm được để nắm bắt context.
- **Áp dụng (Apply)**: 
  - Đưa ra Tóm tắt nội dung file.
  - Nếu user đang code dở, HÃY tự động áp dụng thông tin từ file đó vào code hiện tại của user mà không bắt user phải tự đọc và gõ lại.

# Examples

## Ví dụ 1: Lưu ghi chú mới
**User:** "Lưu lại cách thiết lập TailwindCSS chung cho dự án này nhé, từ nay dùng cái này."
**AI (Action):** Tạo file `.agent/notes/styling/tailwind-setup.md`
**Nội dung file:**
```markdown
---
title: Thiết lập TailwindCSS Chuẩn
date: 2026-03-21
category: styling
tags: [tailwind, css, setup, convention]
---
# Hướng dẫn...
```
**AI (Response):** "Đã lưu thành công vào `.agent/notes/styling/tailwind-setup.md`. Kèm theo các tags: `tailwind`, `css`, `setup`. Từ giờ anh chỉ cần gọi tên tag là em tự tìm lại nhé!"

## Ví dụ 2: Lấy & Tái sử dụng ghi chú
**User:** "Tạo cho tôi 1 nút bấm mới. Áp dụng chuẩn code UI mình đã lưu hôm trước nhé."
**AI (Action):** 
1. Chạy `grep_search` với từ khóa `tags: .*ui.*` hoặc tìm file có chữ `UI` trong `notes/`.
2. Đọc được quy tắc từ file `.md`.
3. Sinh code Component Button theo đúng chuẩn đó cho user ngay lập tức.
**AI (Response):** "Em đã theo chuẩn UI mình lưu trước đó (dùng glassmorphism và indigo-500) để code nút bấm cho anh đây!"
