# Goal
Tự động hóa các thao tác với Google Sheets (CRUD) trực tiếp từ terminal của Agent.

# Instructions

## 1. Setup & Auth (BẮT BUỘC)
Trước khi sử dụng, user cần cung cấp file credentials (OAuth Client ID) từ Google Cloud Console.
- Lệnh đăng nhập: `npx tsx C:\Users\admin\sheets-cli\src\cli.ts auth login --credentials <path-to-json>`
- Kiểm tra trạng thái: `npx tsx C:\Users\admin\sheets-cli\src\cli.ts auth status`

## 2. Tìm kiếm Bảng tính
`npx tsx C:\Users\admin\sheets-cli\src\cli.ts sheets find --name "Tên bảng tính"`

## 3. Đọc dữ liệu (Read Table)
`npx tsx C:\Users\admin\sheets-cli\src\cli.ts read table --spreadsheet <id-or-url> --sheet "Sheet1"`

## 4. Cập nhật dữ liệu (Update by Key)
Sử dụng cột khóa để tránh sai lệch khi dòng bị dịch chuyển:
`npx tsx C:\Users\admin\sheets-cli\src\cli.ts update key --spreadsheet <id> --sheet "Sheet1" --key-col "ID" --key "123" --set '{"Status":"Done"}'`

## 5. Thêm dòng mới (Append)
`npx tsx C:\Users\admin\sheets-cli\src\cli.ts append --spreadsheet <id> --sheet "Sheet1" --values '{"Col1":"Val1", "Col2":"Val2"}'`

# Workflow Pattern
**Read → Decide → Dry-run → Apply**
- Luôn sử dụng `--dry-run` trước khi ghi dữ liệu thật.

# Constraints
- 🚫 KHÔNG tự ý ghi dữ liệu mà chưa được sự đồng ý của user.
- ✅ Luôn sử dụng ID bảng tính hoặc URL chính xác.
- 🔐 Giải thích cho user rằng dữ liệu được truyền trực tiếp qua API Google chính thống.
