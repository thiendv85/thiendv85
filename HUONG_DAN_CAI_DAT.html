⚙️ Yêu Cầu Trước Khi Cài

Windows 10 / 11

🟢
Node.js LTS
Phiên bản 18 trở lên — chưa có thì cài ở Bước 1
🌐
Trình duyệt
Chrome hoặc Microsoft Edge
📦
Thư mục v12
File app (copy từ người dùng khác)
1
Cài Node.js
Chỉ làm 1 lần duy nhất
1 lần
  • Vào https://nodejs.org → tải bản LTS (ví dụ: 20.x.x LTS)
  • Chạy file .msi vừa tải → nhấn Next liên tục → Install → Finish
  • Mở Command Prompt (nhấn Win+R → gõ cmd → Enter) và kiểm tra:
Kiểm tra Node.js
node --version
✅ Thấy v20.x.x (hoặc cao hơn) là thành công!
2
Copy Thư Mục App Vào Máy
Chỉ làm 1 lần duy nhất
1 lần

Copy toàn bộ thư mục v12 vào máy, ví dụ đặt tại:

C:\ATP\v12\
⚠️
Lưu ý: Không đặt trong thư mục có dấu cách hoặc ký tự đặc biệt
✅ Tốt: C:\ATP\v12  |  ❌ Tránh: C:\My Documents\ATP v12
3
Cài Dependencies
Chỉ làm 1 lần duy nhất
1 lần

Mở Command Prompt và chạy lệnh sau:

Command Prompt (cmd.exe)
-- Di chuyển vào thư mục app -- cd C:\ATP\v12 -- Cài các thư viện cần thiết -- node -e "require('child_process').execSync('npm install', {stdio:'inherit'})"
⏳ Chờ 1–2 phút... Thấy "added xxx packages" là xong ✅
4
Khởi Động App
Làm mỗi lần muốn sử dụng
Mỗi lần

Mở Command Prompt và chạy:

Command Prompt (cmd.exe)
cd C:\ATP\v12 node node_modules/vite/bin/vite.js --port 3000
✅ Thấy thông báo này là app đang chạy:

VITE v6.x.x ready in xxx ms
➜ Local: http://localhost:3000/
➜ Network: http://192.168.x.x:3000/
🛑
Để tắt app: nhấn Ctrl + C trong cửa sổ Command Prompt
5
Mở App Trên Trình Duyệt
Làm mỗi lần muốn sử dụng
Mỗi lần

Mở Chrome hoặc Edge → nhập vào thanh địa chỉ:

http://localhost:3000/
🎉   App đã chạy thành công!
📡

Cho Người Khác Xem Trong Cùng Mạng WiFi

Dùng địa chỉ Network hiển thị ở Bước 4, ví dụ:
http://192.168.1.10:3000/
(thay bằng IP thực tế trên màn hình của bạn)

Xử Lý Lỗi Thường Gặp
Lỗi gặp phải Cách xử lý
node không nhận diện Chưa cài Node.js → Quay lại Bước 1
Cannot find module 'vite' Chưa cài npm → Quay lại Bước 3
Port 3000 already in use Đổi port: thêm --port 3001 vào lệnh Bước 4, sau đó vào localhost:3001
App không load dữ liệu Dùng Chrome hoặc Edge (không dùng Internet Explorer)
